# AI 生产级改造统一实施方案

状态：实施中（2026-09-27）。本文是已确认的设计基线，不代表所有能力都已达到生产验收。当前代码已包含持久运行/checkpoint、工具账本与单次确认、上下文快照与保护区、L0/L1/L2 记忆、基础 DLP/引用检查、混合检索/RRF、知识库租户/角色 ACL 和管理界面；后端单测及 MySQL/Qdrant ACL 集成测试已通过。尚未完成或未取得真实环境证据的项目见文末“剩余验收项”。

## 目标与边界

基于现有 FastAPI 单体、LangChain/LangGraph、MySQL、Redis、Qdrant 和 Vue AI 工作台，改造为可恢复、可审计、权限受限、可评测的 Agent Harness + Agentic RAG。沿用现有单服务和异步任务方案，不额外拆分部署服务；新增数据库结构只追加 Alembic migration。除 AI 与共享认证/数据兼容所必需部分外，不改预约等非 AI 业务。

## 统一设计

### 1. Agent Runtime 与工具执行

- 用 LangGraph 显式编排状态：接收/脱敏输入、理解与检索、规划、参数校验、等待用户输入或确认、执行工具、校验结果、生成并验证回答、完成/失败/暂停；关键状态、消息、checkpoint、工具账本及确认记录持久化，浏览器断线不丢运行。
- 查询中断后可恢复。写操作中断后重新展示待执行操作预览并确认；已完成步骤从账本复用结果；执行结果不明时先按幂等键对账，不盲目重试。恢复时重新检查当前身份、权限、租户和业务条件。
- AI 工具范围等于当前登录用户在页面/API 中已有的权限范围，包括管理功能；Agent 不获得独立权限。每次调用均由服务端以当前用户身份做权限、租户、目标对象、状态及参数校验。
- 读工具可自动执行；写工具展示规范化参数、风险及影响并确认一次。预览未实质变化时沿用确认；实质变化需新预览和确认；已不合法则拒绝。原有照片、审批、验收等业务规则不绕过。
- 工具结果以匹配 tool-call ID 的 ToolMessage 入会话，不拼入 system prompt。写操作记录幂等；不设单次运行工具调用总数上限。相同参数的只读调用允许再执行一次，业务状态/结果仍无变化则停止该无进展重复。
- 参数验证失败时，可基于用户原话和受保护上下文修正一次，再经过确定性校验；仍缺参或歧义则提问，不执行。可事务化的批量写操作全成全回滚；不能原子回滚的拆为有明确影响说明的独立确认单元，逐项报告和恢复。

### 2. 上下文与长期记忆

- 最近 5 轮完整对话、当前意图、任务要求/纠正/约束、待确认操作和工具调用/结果配对进入保护区；普通历史可压缩，大结果可卸载并按授权检索。超窗先拆分任务并保留原文；仍有不可拆分内容超限则暂停、解释并请用户缩小/拆分，不静默截断、不以摘要替代保护内容、不自行切换模型。
- L0 原始对话、L1 有来源的场景事实、L2 经用户确认的画像/长期偏好分层保存，始终按 user_id 隔离。相关 L2 优先，不足时再查 L1/L0；归档只在用户明确追溯历史时检索。
- L0/L1/L2 初始 TTL 均 180 天；有效召回满足“实际用于回答/决策”或“用户明确确认有用”之一，同轮同记忆至多计一次。使用频次按已确认的递减增益公式延长 TTL，上限 360 天；过期先归档，归档后连续 180 天未使用才最终删除。
- L0 删除不级联删除派生记忆；遗忘某主题清除相关 L1/L2 及派生副本，保留 L0 独立生命周期。纠正将旧事实失效；一般冲突保留来源并在影响答案时提问。无独立记忆管理页面，用户通过对话纠正/请求删除；删除先展示目标和范围，确认一次；不明确则追问。

### 3. DLP、引用和模型边界

- 用户输入中的敏感信息自动脱敏后继续，提示类别但不回显原文。所有模型/Embedding 输入统一经过 DLP：用户消息、附件解析文本、知识片段、记忆和工具结果。普通对话、日志、checkpoint、向量索引、记忆只使用脱敏数据。
- 按用户已确认的例外，知识库原件仍上传 MinerU，上传前不做本地 DLP；MinerU 输出文本必须在进入聊天模型、Embedding、RAG 或记忆前脱敏，并向管理员说明该边界。
- 输出先在服务端缓冲分段，经 DLP 和适用的引用校验后再发送；保留跨段上下文，未验证的模型原始输出不得传给浏览器，重连/历史回放也只返回验证后的内容。
- 业务事实必须绑定服务端校验过的引用。确定性检查引用存在、版本和当前 ACL；再拆成原子事实，只展示可由引用支持的内容。数值、日期、状态尽量与结构化业务结果确定性比较。点击引用打开侧栏，显示已授权的原文/章节/页码或业务记录。
- 模型只接触敏感业务字段占位符。必须传给工具的原值由服务端短期映射，仅在授权和确认后给指定工具/字段；凭据不进入此通道。映射不得进入通用消息、checkpoint、索引、记忆或普通日志，丢失/过期则重新询问用户。

### 4. Agentic RAG 与中文检索

- 章节完整的文档按章节树切分，过长节点递归切分；无章节资料仅在单设备内递归切分。采用父子块：子块召回，父章节补上下文，引用定位真实文档版本和原片段。
- 检索并行覆盖设备编号/型号等结构化精确查找、管理员审核的学院/全局领域词典、多语言 BM25 词法召回、BGE-M3 稠密向量召回；原查询与仅在口语/歧义时生成的规范查询分别检索，以 RRF 合并并重排。块大小、候选深度及重排阈值由项目语料评测确定。
- Qdrant 使用支持多语言 tokenizer 的目标版本（至少 1.16.0），并行构建新索引、验证、切换和保留回滚路径。元数据覆盖租户/资源范围、文档版本、锚点、父子关系、稳定 ID/内容哈希、解析/分块/词典/模型版本和 generation；记忆索引与共享知识索引隔离。
- Qdrant 先按当前 Principal 可见范围过滤，候选返回后仍以 MySQL 状态/ACL 再校验；任何未经授权的块不得进入模型或引用 UI。增量更新由稳定 ID、版本和 generation 支持。

### 5. 前端与运营

- 改造现有 AI 工作台：显示运行/恢复状态、正在执行的步骤、工具结果和失败恢复提示；写操作内联展示结构化预览、风险、影响及单次确认；引用通过侧栏检查；DLP 显示已脱敏类别；支持对话式纠正和删除记忆，不增加独立记忆管理页面。
- 管理端提供领域词典维护（全校/学院范围、标准词/别名、忽略词、启停和版本）。知识库发布与索引重建继续由授权角色操作，并展示解析/审核/索引状态及可回滚信息。

## 数据与迁移原则

- 先盘点当前 AI ORM、Alembic、LangGraph 节点、运行记录、ToolExecution、会话消息和 Qdrant collection；将本方案映射到现有结构，避免重复造表。
- 缺失字段/表只追加 migration；旧消息与知识索引按兼容策略迁移。新索引采取并行构建、校验、切换、回滚，不原地破坏现有可用索引。
- 所有新记录按 user_id/tenant 和 owner 做访问隔离；业务权限从当前 MySQL 主体读取，Redis/向量 payload 不能成为最终授权事实。

## 验收门槛

1. 单元测试：Runtime 状态迁移、checkpoint 恢复、超时/异常分支、工具 schema/业务校验、幂等/无进展、单次确认、DLP、记忆 TTL/归档/纠正/删除传播、引用原子事实验证、中文词典和 RRF。
2. 集成测试：真实 MySQL migration/事务/幂等账本，真实 Redis 会话/限流/恢复路径，Qdrant BM25+dense 检索、ACL prefilter 与 MySQL postcheck、索引切换和回滚；不能用 SQLite/mock 代替这些结论。
3. 故障测试：进程在模型调用、待确认、工具执行、工具结果落库、通知或索引切换时中断；验证恢复不丢状态、不重复业务写入、不泄漏敏感原文。
4. 安全测试：跨学院/用户记忆及引用访问、用户禁用/换学院/撤权后旧 run 恢复、伪造占位符、提示注入越权、敏感输入/工具输出/异常日志/重连回放 DLP。
5. RAG 评测：构建真实且按学院/设备授权标注的评测集，测 Recall@K、MRR/NDCG、引用支持率、错误引用率和拒答/澄清；指标阈值在基线跑出后再定，不能用人工挑例子代替。
6. 前端 E2E：普通用户、实验室负责人、系统管理员分别使用独立浏览器上下文；覆盖多轮口语改写、检索引用侧栏、写预览确认、冲突/越权、运行中断恢复、敏感输入提示、记忆纠正/删除确认、管理员词典和索引状态。核对实际页面、接口和持久化结果。

## 当前剩余验收项

- 敏感业务字段的短期原值映射通道尚未完成端到端实现；当前 DLP 的脱敏/扫描不能据此宣称“模型占位符可安全还原给指定工具”。
- 受保护上下文超出模型窗口时的自动任务拆分尚未完成；目前不得静默截断，超限场景仍需作为明确限制验收。
- 尚无标注充分的 RAG 评测集与 Recall@K、MRR/NDCG、引用支持率基线，检索质量不能称为量化达标。
- 已验证 MySQL/Qdrant 上的知识 ACL 查询，但尚未完成真实大索引的蓝绿重建、切换和回滚全流程验收。
- 本轮未执行真实聊天模型、Embedding 服务和 MinerU 的外部调用验收；需要配置有效服务并显式运行对应 smoke/integration 检查。
- 前端目前验证了管理员 AI 工作台与知识范围配置页面；普通用户/负责人多角色 AI 运行恢复、记忆生命周期及引用详情的完整浏览器链路仍需补齐。
7. 项目既有约定要求的真实模型 CI 冒烟与质量用例继续执行；凭据只从安全配置读取，不进入代码、日志和报告。

验收仅在适用测试实际通过后报告；外部模型、MinerU 或容器服务不可用时分别列为未验证阻塞，不能标成通过。
