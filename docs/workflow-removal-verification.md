旧本地业务备份已用清理后的业务数据重建，不保留被删除模块的历史备份。校验摘要和测试日志位于忽略的 `.artifacts/`，不提交业务备份或凭据。

## 其他环境升级

先停止旧 API 并使用新 JAR 执行新增迁移；原 V1～V3 不改写。迁移期间自动停用 Worker 与通知消费。

```powershell
java -jar backend-java/target/labflow-backend-1.0.0.jar --spring.main.web-application-type=none --labflow.migration=migrate
cd backend
uv run python scripts/remove_retired_workflow_stream_history.py
```

随后启动新 API 和前端。附件删除只针对不被保留业务引用的文件，启动失败或中断后再次启动可继续完成。旧模块地址和维护证据专属下载地址均移除，共用附件使用保留业务的下载地址。重新部署前应同步替换含旧模块历史的业务备份。
