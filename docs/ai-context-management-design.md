# AI 上下文管理设计

状态：设计基线已确认；上下文实现与验收进度以 [AI 生产级改造方案](ai-production-upgrade-plan.md) 为准。本文记录目标行为，不单独代表已完整实现。

## 保护范围

最近 5 轮完整对话、当前请求、待确认操作、尚未完成的工具调用和结果配对，以及更早但仍有效的任务要求、纠正和未解决约束，均受保护。普通历史可压缩，大结果可卸载并通过授权检索取回。

## 保护内容超出窗口：已选择拆分执行

受保护原文完整保存，任务分解为子任务，各自加载相关原文，最后汇总结果。保护不要求每个子任务加载全部历史，但适用于该子任务的要求不能因拆分而丢失。

拆分不扩大用户授权，也不自动增加新服务或多 Agent 部署；各子任务仍遵循业务权限、写操作确认和中断恢复规则。

## 后续设计与验收需覆盖

- 全局约束与各子任务的适用要求映射、原文溯源，以及汇总阶段的要求覆盖检查。
- 预留模型输出及工具消息容量，保持工具调用与结果配对有效。
- 拆分后单个不可再拆分的必要内容仍然超限时，暂停处理并明确报告容量限制，请用户缩小或拆分请求；原文继续保存在 checkpoint，不静默截断、不用摘要替代保护原文，也不擅自切换模型。

## 口语查询和指代消解：已选择先检索再澄清

结合当前会话的受保护上下文改写不完整/口语输入，同时保留原始输入；两种表达都进入混合检索。若检索后仍有多个候选，或写操作缺少必要设备、日期等参数，询问用户。改写不得凭空补造会改变对象、范围或业务动作的内容；写操作预览以用户确认的明确参数为准。
