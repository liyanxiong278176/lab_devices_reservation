# ADR-0018：本次重构只覆盖桌面 Web

- 状态：已接受
- 日期：2026-08-26
- 决策人：项目负责人

## 决策

本次不开发原生移动 App，也不把手机端响应式作为交付目标。前端以桌面 Web 为主要运行环境，优先优化：

- 三栏 AI 工作台；
- 设备搜索、日期日历和预约创建；
- 负责人审批、报修和设备管理；
- 管理员数据驾驶舱和审计视图。

浏览器窗口变化只需保证基本可用和不破坏关键确认操作，但不承诺完整移动端工作流。

## 影响

- 可以使用更高的信息密度和更完整的三栏布局。
- 减少移动端导航、手势、表格折叠和设备兼容的额外工作。
- 后续若需要移动使用，可基于 `/api/v2` 和事件协议开发独立移动端，不反向污染桌面信息架构。
