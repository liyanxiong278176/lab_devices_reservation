# ADR-0007：普通用户和负责人单学院归属

- 状态：已接受
- 日期：2026-08-26
- 决策人：项目负责人

## 决策

普通用户和实验室负责人各自归属于一个学院。负责人可以在该学院内负责多个实验室，但默认不能跨学院管理资源。跨学院查看或操作只属于系统管理员，或未来通过独立的、可审计的显式授权实现。

学院归属必须使用正式外键/关系，而不是 `dept_name` 文本。负责人和实验室之间允许一对多授权关系，且被授权实验室必须属于负责人的学院。

## 影响

- 普通用户的学院范围可以直接进入认证上下文和数据库查询条件。
- 负责人管理范围需要通过实验室负责人关系校验，不能只检查角色名。
- 数据模型和接口不需要处理普通用户的多学院选择，降低缓存、审计和 AI 检索范围混淆风险。
- 若未来出现跨学院联合课题或共享设备，应新增显式授权/共享模型，不能修改默认隔离规则来绕过它。
