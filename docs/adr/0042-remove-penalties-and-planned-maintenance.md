# 移除违规申诉与维护校准流程

为精简业务，移除完整的违规处罚、信用扣分、申诉及周期维护、校准、安全检查计划模块，并删除这些模块的历史记录和专属附件。普通报修、损坏归还处理和维修中设备不可预约的规则继续保留；共用附件及原有预约、报修、归还验收记录保留。

取消爽约及逾期提醒、跟进、升级、处罚和预约冻结流程。首日未领用的已批准预约自动取消并释放设备占用，原因记为“未在预约首日领用”；已领用设备继续占用直到归还验收完成。解除旧处罚和计划维护/校准造成的限制，不自动恢复此前被取消或驳回的预约。

## 后续影响

删除前后端入口、接口、相关权限与后台任务，清理对应历史通知和模块操作日志；保留预约与设备状态的实际操作记录。删除专属附件前检查共享引用，防止影响报修和验收。数据库变更通过新增迁移执行，不改写已执行的迁移；验证预约取消、设备占用、普通报修、损坏归还、租户隔离以及历史清理结果。

V4 清理专属表与附件引用，V5 清理不同版本的通知任务及通知历史。附件文件通过待删除路径队列完成，失败时下次启动继续，不归档被删除的附件。
