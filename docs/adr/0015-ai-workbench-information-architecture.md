# ADR-0015：AI 采用三栏工作台而非悬浮球

- 状态：已接受
- 日期：2026-08-26
- 决策人：项目负责人

## 决策

前端左侧主导航增加独立的“AI 工作台”目录，点击后进入完整页面，不再以悬浮球作为主要入口。页面采用三栏结构：

- 会话栏：新建/搜索/归档会话，显示运行状态和待确认标记；
- 对话与执行栏：用户消息、流式回答、Agent 步骤、工具调用、确认卡片和结果；
- 上下文栏：知识库引用、设备/预约结果、任务状态、来源版本和可跳转业务对象。

AI 页面必须能承载长流程、断线恢复、失败重试和确认动作，而不是只展示一段文本。预约、设备等业务操作可以从 AI 卡片跳转到对应业务页面，AI 不取代普通表单和管理页面。

## 影响

- 需要设计版本化的 Agent 事件协议，而不是只传文本 delta。
- 前端要维护会话、执行步骤、工具调用和引用的状态模型，并处理重连补偿。
- 三栏在窄屏上需要退化为可切换面板，不能牺牲核心确认操作的可见性。
