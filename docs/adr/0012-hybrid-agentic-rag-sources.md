# ADR-0012：采用文档 RAG 与结构化业务工具混合的 Agentic RAG

- 状态：已接受
- 日期：2026-08-26
- 决策人：项目负责人

## 决策

第一版知识库包含经过管理员上传、审核和发布的：

- 全校通用预约规则、安全制度和 FAQ；
- 学院实验室制度；
- 设备使用手册、操作 SOP 和维护说明。

全校文档可被所有登录用户按权限访问，学院文档必须带 `college_id` 并在检索时强制过滤。文档保存来源、版本、生效时间、审核人和片段定位，回答需要提供可追溯引用。

设备实时状态、可用日期、预约、审批、报修和个人数据不作为普通向量文本的事实来源，而由 Agent 调用有权限的结构化后端工具查询。Agent 可以组合两类来源：先检索制度/手册，再查询当前业务状态，最终区分“文档依据”和“实时数据”。

未经脱敏的聊天记录和个人隐私不进入第一版知识库。

## 影响

- 避免向量索引过期导致 AI 把已占用设备说成可用。
- 学院隔离可以统一落实到文档 metadata 和工具 SQL 条件，而不是依赖提示词。
- 需要建设文档上传、解析、切分、嵌入、索引、版本、发布、撤回和重建流程。
- 需要评测检索命中、引用正确性、权限过滤和“该查实时工具而不是 RAG”的路由准确率。
