# ADR-0016：采用科学运营控制台视觉方向

- 状态：已接受
- 日期：2026-08-26
- 决策人：项目负责人

## 决策

前端重构采用面向实验室运营的“科学运营控制台”方向，而不是通用后台或泛化的 AI 紫色渐变模板：

- 深石墨/深蓝底色承载高密度设备、日期和任务信息；
- 冷青色表达交互、数据和 AI；
- 绿色表达可用、成功和已完成；
- 琥珀色表达待审批、风险和冲突；
- 红色只用于不可用、失败和高风险动作；
- 使用清晰的数字层级、状态标签、日期块和执行时间线；
- 动效用于流式 AI、状态变化和导航反馈，不用于持续干扰或装饰性炫技。

学生、负责人和系统管理员共享设计令牌，但根据权限显示不同的任务入口和数据范围。AI 工作台和业务页面必须在状态颜色、卡片、表格、日历和确认交互上保持一致。

## 影响

- 需要重新整理前端 design tokens、布局、基础组件和图表主题。
- 不能只替换首页；设备、预约、审批、报修、通知和 AI 页面要形成统一体验。
- 要兼顾高信息密度与易读性，在窄屏下将三栏工作台退化为可切换面板。
