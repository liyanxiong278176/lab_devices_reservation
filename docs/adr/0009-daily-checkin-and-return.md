# ADR-0009：按自然日定义签到、归还和爽约

- 状态：已接受
- 日期：2026-08-26
- 决策人：项目负责人

## 决策

预约界面和业务条件只使用自然日，但保留履约状态：

- 单日预约：用户在预约日期签到并在当天完成归还。
- 连续多日预约：在开始日期签到，在结束日期归还；中间日期持续占用设备。
- 重复/批量预约：每个生成的预约日期独立签到、归还、爽约和统计。
- 已批准预约超过规定日期仍未签到时，由可靠定时任务标记为 `NO_SHOW`，释放后续可用占用并发送通知；具体日界线以系统时区定义。
- 管理员可以在有审计记录的前提下修正异常履约状态。

用户不需要输入或选择时分秒；系统内部可以保留 `check_in_at`、`check_out_at` 和任务执行时间，用于审计、排序和故障排查。

## 影响

- 状态机仍然支持 `APPROVED → IN_USE → COMPLETED`，但合法性判断从时间点窗口改为日期边界。
- 多日预约的设备占用不能因为首日签到而释放，必须保持到结束日期归还或被取消。
- 定时任务必须幂等、可恢复，并使用条件更新避免覆盖用户已完成的签到/归还。
