# ADR-0009：按自然日定义预约履约时间边界

- 状态：已接受；交接与验收流程由 [ADR-0030](./0030-universal-reservation-handover.md) 更新
- 日期：2026-08-26
- 决策人：项目负责人

## 决策

预约界面和业务条件只使用自然日，但保留履约状态。当前履约角色和交接要求以 ADR-0030
为准；本 ADR 继续定义日期粒度、连续日期占用和重复预约独立性：

- 单日预约：预约日完成负责人交接；用户归还后由负责人验收完成。
- 连续多日预约：开始日期由负责人交接，结束日期用户归还并由负责人验收；中间日期持续占用设备。
- 重复/批量预约：每个生成的预约日期独立交接、归还、验收、爽约和统计。
- 已批准预约在首日结束前仍未完成负责人交接时，由可靠任务标记为 `NO_SHOW`，释放后续可用占用并发送通知；具体日界线以系统时区定义。
- 管理员可以在有审计记录的前提下修正异常履约状态。

用户不需要输入或选择时分秒；系统内部可以保留交接、归还、验收和任务执行时间，用于审计、排序和故障排查。

## 影响

- 状态机通过 `APPROVED → IN_USE → RETURN_PENDING → COMPLETED` 完成履约，但合法性判断仍以自然日为边界。
- 多日预约的设备占用不能因为首日交接而释放，必须保持到结束日期验收或被取消。
- 定时任务必须幂等、可恢复，并使用条件更新避免覆盖已完成的交接、归还和验收。
