# ADR-0026：Outbox 任务采用退避重试和可人工恢复的失败状态

Outbox 任务对网络、Redis 或数据库等可恢复错误使用带随机抖动的指数退避重试；参数错误、权限错误和目标数据不存在等确定性错误直接进入失败状态。超过最大重试次数的任务进入 `FAILED`/死信状态，记录最后错误和重试次数，由管理端或运维流程确认原因后手动重试。所有任务处理继续依赖幂等键，重试不能重复产生业务副作用。

## Consequences

- 短暂依赖故障不会立即丢失任务，也不会形成紧密重试风暴。
- 失败任务可见、可统计、可恢复，不需要直接修改业务数据补救。
- 需要保留错误摘要、重试次数、下一次执行时间和人工操作审计。
