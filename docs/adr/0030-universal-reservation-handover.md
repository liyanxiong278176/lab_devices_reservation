# ADR 0030：所有预约统一经过设备交接与归还验收

## 状态

已采用。

## 背景

此前只有允许外借的设备才进入负责人交接流程，普通设备可在审批后由预约人直接签到、归还并自报设备状态。这样同一套预约系统存在两种履约路径，设备责任交接和归还状态确认不一致。

## 决策

1. 不论设备是否允许外借，每笔预约审批通过后都必须由负责该实验室/学院的负责人完成现场交接，交接完成后才能开始使用。
2. 用户在预约结束日提交实际归还后，预约进入待验收；负责人完成归还验收后预约才完成，设备状态再按验收结果更新。
3. 连续多日预约在首日交接、结束日验收；重复预约生成的每个日期仍是独立预约，分别交接和验收。
4. 设备的“允许外借”属性仍表示是否允许设备离开实验室，不再决定预约是否需要负责人交接。
5. 规则启用时，已审批的未完成预约转为待交接；仍在使用中的预约保持使用中，不伪造历史交接时间或负责人，用户实际归还后进入负责人验收。已完成的历史预约不回溯修改。

## 结果

- 预约申请、审批通知、爽约时限、用户预约详情和负责人交接队列都采用同一条履约流程。
- 现有交接记录表承载普通设备和外借设备的交接与验收，不改变自然日预约粒度，也不引入第二套状态机。
- 设备负责人仍只能处理自己授权的实验室/学院范围内的交接与验收。
- 本决策仅调整非 AI 预约履约流程；AI 工具和 AI 数据链路不在本 ADR 范围。
