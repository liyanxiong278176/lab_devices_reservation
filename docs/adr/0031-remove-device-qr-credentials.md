# ADR 0031：移除设备二维码凭证

## 状态

已采用。

## 背景

设备扫码只是归还流程中的可选校验入口，却引入了摄像头权限、浏览器兼容、二维码凭证生成/存储/校验以及独立数据库字段。当前履约流程已要求用户从自己的预约记录提交归还，并由负责人现场交接和验收，二维码不是完成预约闭环的必要条件。

## 决策

1. 移除摄像头扫描、二维码手工输入、`qr_token` API 字段、生成逻辑和后端校验。
2. 通过新增 Alembic revision 删除 `device.qr_token` 列和唯一索引，不修改既有 migration；已有 token 随迁移删除，降级只重建空列。
3. 保留预约记录上的归还提交、现场照片、负责人交接和验收流程。

## 结果

- 用户仍从本人预约记录提交归还，服务端继续验证预约归属、学院、预约日期和状态。
- 负责人仍通过现场记录、照片和配件检查完成交接与验收。
- 不再需要摄像头权限或设备二维码；接口和部署模型中不再保存二维码凭证。
