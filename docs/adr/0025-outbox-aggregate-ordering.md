# ADR-0025：Outbox 按业务对象并行、按聚合键串行

Outbox worker 对不同业务对象使用有界并发处理；同一预约、设备或报修单相关的任务通过 `aggregate_key` 归组，并按任务创建/执行顺序串行处理。任务领取仍使用数据库租约和幂等键，聚合键只负责降低同一业务对象的乱序风险，不替代状态机条件更新。

## Consequences

- 不同业务对象之间可以并行，提高任务吞吐量。
- 同一业务对象的通知、缓存失效和状态后续动作具有稳定顺序。
- 任务表需要保存聚合键和可排序的任务序号/创建时间，worker 需要避免同一聚合键同时被多个消费者处理。
- 全局并发上限和单任务超时必须配置化，防止异步任务耗尽数据库连接和事件循环资源。
