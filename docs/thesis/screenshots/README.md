# 系统运行截图

截图用于记录当前 FastAPI `/api/v2` + Vue Web 的实际页面效果。AI 工作台不属于本次
非 AI 业务改造范围，截图重点覆盖权限、预约、设备、通知和报修链路。

## 普通用户页面

- 仪表盘：只展示本人及所属学院范围的数据。
- 设备：只能浏览所属学院设备，预约入口以自然日选择为单位。
- 我的预约：展示待审批、已通过、使用中、已完成、取消、违规和爽约状态。
- 我的通知：点击未读只更新已读状态，当前通知不会从列表消失，右上角未读数即时减少。
- 提交报修 / 我的报修：支持 JPG、PNG、WebP 图片上传，单图 5MB，附件按学院隔离。

## 管理员页面

- 仪表盘、设备：仅展示本人负责学院或实验室范围内的数据。
- 待审批：普通用户提交预约后进入负责人范围内的审批队列。
- 报修处理：`PENDING → PROCESSING → RESOLVED/REJECTED`，受理人不能被其他负责人越权接管。
- 设备管理：设备状态变更会写入生命周期历史，维修中的设备不可预约。
- 用户管理：系统管理员可创建、启停、改角色和改学院；禁用或改密码会撤销刷新会话。

## 采集方式

```powershell
cd frontend
pnpm dev

cd ../backend
uv run uvicorn app.main:app --reload --port 8000
```

页面通过 Vite 代理访问 `/api/v2`。真实联调时应使用三个学院、一个普通用户和一个
负责人分别验证跨学院访问返回 404/403，不能只凭导航菜单是否隐藏判断权限。
